# Population-level observables

Not part of the ported Monte Carlo model. FSPS-tabulated
population-level luminosities, wired into `ClusterSimulation.run()`'s
per-timestep output alongside `lumx_tot`/`nphot_tot`.

## Bolometric luminosity, L_bol(t)

Main-sequence bolometric luminosity, sourced from FSPS
(Padova/Geneva-track SSPs), not the Starburst99 tracks the original
2009 Fig. 1 was almost certainly produced with — a documented
literature-level systematic (up to a factor of a few, ages 3-20 Myr),
not a bug.

`lbol_tot = ms_lbol + lumx_tot`.

Implementation: `io/tables.py::MSLuminosityTable` (`get_lbol`,
fiducial-mass table rescaled by `BinaryPopulation.total_mass_msun`),
`simulation/cluster.py::ClusterSimulation.run()`.
Tests: `tests/test_ms_luminosity_table.py` (linear mass scaling, zero-
mass/zero-luminosity, no-extrapolation domain boundary, all three
metallicity tables), `tests/test_cluster_simulation_observables.py`.

## Far-UV luminosity, L_UV(t)

GALEX FUV (~1528 Å), via FSPS `get_mags(bands=["galex_fuv"])`.
MS-only — no accretion/UV spectral model exists for the HMXB
contribution.

Implementation: `io/tables.py::UVLuminosityTable` (mirrors
`MSLuminosityTable`'s fiducial-mass-then-rescale convention),
generated by `scripts/generate_fuv_luminosities.py`.
Tests: `tests/test_uv_luminosity_table.py`.

## Ionising photon rate, Q_H(t)

`qh_tot = qh_ms_tot + nphot_tot`:

- `nphot_tot` — the HMXB accretion-driven proxy,
  `NPHOT_PER_LUMX * lumx_tot` (Power et al. 2013 conversion,
  `docs/provenance.md` Section 3).
- `qh_ms_tot` — the massive-star population's own ionising-photon
  output, summed per star over currently-alive `M >= 8` Msun stars,
  using `IonizingPhotonTable.get_ngamma(mass)` (interpreted as the
  total photon count over the star's whole MS lifetime, divided by
  `LifetimeTable.get_lifetime(mass)`). Cross-checked against Vacca,
  Garmany & Shull (1996, ApJ 460, 914)'s O/early-B ionising rates at
  10/40/80 Msun.

Implementation: `simulation/cluster.py::ClusterSimulation._qh_ms_tot`.
Tests: `tests/test_cluster_simulation_observables.py`.

Note: `binary_prescription="single"` tracks `m1` with `m2 = 0`
placeholders (same mechanism as `binary_fraction < 1`,
[`binary-sampling.md`](binary-sampling.md)) rather than emptying the
population array — `_qh_ms_tot` reads `m1`/`nturn` directly, so single
stars still contribute to `Q_H`/`L_bol` (correctly, since massive
single stars still ionise) while `L_X`/HMXB activation stay zero
(`m2 = 0` blocks that unconditionally).

## X-ray luminosity, L_X(t)

`lumx_tot`, the ported baseline quantity — see `docs/provenance.md`
Section 3.
